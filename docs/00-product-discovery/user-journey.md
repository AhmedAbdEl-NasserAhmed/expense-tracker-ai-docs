# User Journey

## Initial Journey

1. User creates an account.

2. User completes the financial profile.

3. The application calculates the user's available monthly income.

4. The user begins recording daily expenses.

5. The application builds spending history.

6. After approximately one month of activity, the application analyzes spending behavior.

7. The application provides personalized financial insights.

8. The user creates financial goals.

9. The application recommends actions that help the user achieve those goals.

10. The application tracks the user's progress over time.
