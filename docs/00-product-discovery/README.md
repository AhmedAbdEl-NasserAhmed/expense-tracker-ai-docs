# Product Discovery

## Purpose

The purpose of this phase is to define the product before making any technical decisions.

At the end of this phase we should have a clear understanding of:

- Why this product exists.
- Who it is built for.
- What problem it solves.
- How the user interacts with it.
- The assumptions we are making.
- The product decisions we have agreed on.

This phase intentionally avoids discussions about:

- Architecture
- Database
- APIs
- Frontend
- Backend
- Technology choices

Those topics belong to later phases.
