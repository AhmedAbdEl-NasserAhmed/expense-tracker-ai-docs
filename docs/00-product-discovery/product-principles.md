# Product Principles

## 1. Encourage, Never Shame

The application should motivate users instead of making them feel guilty about their spending.

---

## 2. Be Honest

Recommendations must always be realistic.

If a financial goal is currently unrealistic, the application should explain why and provide a practical path toward achieving it.

---

## 3. Build Trust Before Giving Advice

Recommendations should only be generated after sufficient financial data has been collected.

---

## 4. Focus on Decisions

The application exists to improve financial decisions rather than simply record expenses.

---

## 5. Give Users Hope

Every interaction should leave the user feeling that progress is possible through consistent financial behavior.
