# User Stories

## Authentication

- As a user, I want to create an account with email/password so I can access my financial profile.
- As a user, I want to sign in with Google so I can access the application conveniently.
- As a user, I want to reset my password by email so I can recover access to my account.

## Onboarding

- As a new user, I want to provide my financial information so the application can understand my starting position.
- As a new user, I want to select the expense categories I use so they are ready when I record expenses.
- As a new user joining partway through a month, I want to provide my available spending capacity for the remainder of the month so the application starts from an accurate point.
- As a new user, I want to reach the dashboard immediately after onboarding so I know what to do next.

## Expenses

- As a user, I want to record an expense quickly so tracking does not become a burden.
- As a user, I want to use previous dates so I can correct missed days.
- As a user, I want to enter multiple expenses in one session so I can catch up efficiently.
- As a user, I want to edit or delete an expense so mistakes do not corrupt my financial history.
- As a user, I want to mark an expense as recurring when appropriate so I do not need to recreate the same recurring rule repeatedly.

## Financial Understanding

- As a user, I want to see how much spending capacity remains this month so I understand my current position.
- As a user, I want to see a daily spending guidance amount so I can understand how much I can reasonably spend today.
- As a user, I want to see spending by category so I know where my money goes.
- As a user, I want to review previous expenses so I can understand and correct my history.
- As a user, I want to review previous months as complete financial periods so I can understand how I performed.

## Financial Profile

- As a user, I want to update my income and income streams so the application reflects my current situation.
- As a user, I want to manage recurring expenses and commitments so future spending capacity is accurate.
- As a user, I want to update my savings when my real savings change.

## Notifications

- As a user, I want one daily reminder when I have not recorded expenses so I can maintain consistent tracking without being overwhelmed.
- As a user, I want to catch up on missing days later so a missed day does not cause me to abandon tracking.

## Goals

- As a user, I want to create a financial goal separately from onboarding so I can define what I want to achieve when I am ready.
- As a user, I want future guidance to be based on my actual financial behavior rather than assumptions.

## Account Control

- As a user, I want to permanently delete my account and financial data so I remain in control of my information.
